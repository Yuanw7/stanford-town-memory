# 模型能力诊断题集

已提供两个独立合成题集：20 道开发题和 50 道验收题，每类分别 4 / 10 道。覆盖事实、时间更新、关系、承诺理解、无答案。开发集的人物和地点与验收集分开，问题 ID 和事件 ID 不重复。

问题文件只包含查询和最小必要证据；`.answers.jsonl` 仅供本地评分，执行器不会将答案发给模型。所有查询使用相同系统提示和单轮只读回答，不改变角色记忆。

来源是项目作者构造的合成场景，不是现实人物数据。当前审核状态为 `pending_independent_human_review`，不能宣称已完成人工独立审核。运行会把问题、答案文件的 SHA256 写入 manifest；冻结后任何修改都会产生新版本。

严格答案格式为 `{"answer":"..."}`。日期、时间和人名有固定格式；失败、无效 JSON、输出截断都记为错误。输出格式正确率和问答正确率可分别分析。未来增加同义答案须先冻结答案版本，不能为某次模型输出事后放宽。

承诺类测试的是承诺日期理解，不是在线承诺履行率。在线履行指标在 P4/P5 另行实现。

## 固定工作负载数据

workload-100.jsonl / workload-1000.jsonl 包含五个角色的 100 / 1000 条观察，以及固定的 50 个查询。来源是能力验收的合成场景加无关观察，输入顺序和角色作用域冻结；workload.answers.jsonl 独立用于运行后评分，不发给模型。empty-state.json 是空初始观察快照。

目前仅 full_history_control 诊断执行已运行，不构成 memory 策略优化比较。数据的人工审核状态沿用 pending_independent_human_review。
