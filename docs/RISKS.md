## 本地运行发现与公共修复

- R20（已复现并修复）：零消息邀请可在同一仿真步创建并取消，未形成归档；原版仍标记 toRemember，后续报 Conversation not found。c:683 实测 active=false、archived=false、messageCount=0。修复仅跳过零消息会话，真实对话保持记忆；2 项回归测试通过。
- R02（已修复）：同分重要性归一化分母为 0，导致 NaN。相同分值贡献 0，普通范围保持原公式；此公共修复会让所有后续策略继承，早期未修复运行不混作同版本基线。
- R21（验收工具误报，已修复）：generationNumber 是每步版本号，不是重启计数。改用独立控制计数，normal generation 增长不再使验收失败；保留假失败 artifact 作为工具问题证据。
- R22（计量边界）：客户端转发耗时包含模型服务内部等待。网关只精确测量自身排队；不得把 proxyForwardMs 命名为纯推理时间。
- R23（实验规模口径，已确认）：现有全镇 100/1000 条观察对应每角色 20/200 条，不能称每角色 1000 条长期记忆；每个报告分别记录观察、会话、派生记忆数量。
- R24（预算可能不生效，待验证）：默认 Top-K=3 的短记忆可能远低于扫描预算，策略无差异是合法结果；不通过同时提高 K 制造收益。记录预算命中与跳过率，修改 K 单独消融。
- R25（留出集偏差，需规避）：同一题集反复诊断后再用于策略调优可能影响验收可信度；保留既有结果，开发用独立题集，正式策略验收另冻留出集并人工核验。
- R26（任务指标缺失，已确认）：现有承诺题只有问答，不能给出履行率；正式完整质量门槛依赖实际接受、到期、执行和完成证据。
- R27（已复现）：受控反思对 60 条输入生成三项 insight 时可能重复列出长 statementIds，512-token 输出上限不足，JSON 被截断。初次 run 为 artifacts/local/memory-write-smoke/2026-10-15T02-31-57-132Z-928165c8；拒绝部分结果，另用 1024 配置做有界复测。较大输出上限增加成本，是独立实验变量，不冒充 memory 优化。
- R28（已观察）：世界停止后 agent 的 inProgressOperation 标记可能保留并随墙钟变为 stale。当前读取为引擎已停止但含遗留标记；不自动清理或宣称在线故障恢复通过。开发捕获需显式允许并留档，正式捕获仍需证明排空。
- R29（已确认并兼容）：安装版本的 Convex CLI 即便 --format json 仍可输出 Bytes(...)、bigint 等扩展字面量。直接 JSON.parse 导出 worlds 会失败。新增无 eval 的受限数据解码，字符串内容保持不变，回归测试通过。
- R30（已观察，根因待逐会话验证）：归档 numMessages 与持久化 messages 行数不一致，本次可映射归档通常多一条持久化消息。源码先写 messages 再排队 finishSendingMessage，计数异步更新可能参与形成差异；未核验各条队列输入的执行状态，不能据此断言全部因果。默认排除，开发显式模式保留实际行并标注。
- R31（时间口径修正）：归档文档 _creationTime 是归档写入时间，晚于实际会话开始及部分消息；用它作 v2 开始时间会错误排除消息。捕获改用归档 created 字段，原始归档写入时间单独保留；旧捕获证据不改写。
- R32（已复现）：较小记忆预算会整条跳过包含承诺/时间更新的记忆；128 压力组本场景只保留旧关系摘要，事实/承诺弃答且投递等待。查询输入约减 59.44%，但准确率由 90% 降至 40%，模拟器完成由 3/3 降至 0/3。该负面结果不推广为所有小预算必然失败。
- R33（已复现，唯一根因未确定）：基线历史题在完整选中摘要上下文中答当前时间；更新摘要实际含历史时间。换成全量原始消息或指定相关原文后答对，支持研究表达/干扰因素，不足以证明单一模块负责全部错误。
- R34（评估误读风险）：弃答可以降低已确认矛盾数，却同时损害召回与履行。必须联合报告准确率、弃答/未评覆盖、矛盾及任务事件，不把未评当正确。

- R36（设计限制）：引用匹配、值在原文中及合法 JSON 均不证明语义蕴含。主语、否定关系、生效日期和完整性仍可能错误；实体/属性命名不一致可能阻止替换。需独立留出数据、人工审核与来源召回评估；不能只凭序列化校验称事实正确。
