## D015：分层原型独立维护与严格抽取边界

- 日期：2026-10-15；状态：本地最小原型已实现，真实模型诊断中，正式验收未完成。
- 不复用 baseline 摘要作为分层事实来源；各组从同一可见原文独立建立状态，完整计入抽取、向量、查询规划、回答和动作消耗。未实现的归档回查不由配置键冒充已接入。
- 普通 JSON 生成会漏必填字段并生成无原文支持的属性；失败批次全部拒绝并保留运行。另以独立配置增加 JSON Schema 解码，不填默认事实、不采用部分合法条目发布、不放宽来源校验。
- 生效时间和观察时间分开，显式替换只改变读取视图；歧义冲突保留。实际执行回执独立于模型记忆和评估目标，恢复后重验。
- 先用既有开发失败例作诊断；不能据此当作独立留出集通过。单次配置只验证流程，完整重复矩阵与人工审核保持待项。

- D015 补充：JSON Schema 不能阻止生成原文没有的 true/false 或代词解引用。纠错最多一次，单独记录 extractionAttempt，传输失败/超时直接传播。另以独立配置限制事实值为当前原文句子，保留更长输入的成本风险；仍由提交校验检查值与引用对应，不允许跨句拼接伪造来源。

## D018：将逐问规划和来源时效约束拆成独立开发消融

- 日期：2026-10-15；状态：规则规划、来源日期约束和引用协议已实现，开发模型对照中，未正式验收。
- 保留原 LLM 规划，另增 deterministic_any_v1：只解析问题中的明确日期；仅明确承诺/接受语言缩小到 commitment，其余保留 any。多日期、无效日期或未来日期显式拒绝，不猜答案、不使用问题 ID/类别。解析覆盖有限，保留质量对照。
- dated_sentence_schema_v1 把原文句子、来源 ID、有效日和替换标记绑定。支持 ISO 日期、英文月份日期和带会话年上下文的部分日期/today；不猜截止日为有效期起点。多日期/多钟点或期限边界关系排除并留原因，原文归档不删。替换仅使用明确 update/now 等提示且不含历史重述标记，不能等同通用语义正确性。
- 原版日期解析会将无效英文日期滚动到下月，已用严格日历检查替代；新对照各组共用此输入修复，当前冻结开发题不含这些无效日期。日期约束不是来源或事实蕴含的完整证明。
- 四组第一轮分别形成 queryPlanner、extractionFormat 的单因子对照边。report 校验配置仅变一个因子，并核对原始维护事实是否一致；若规划对照发生维护漂移，不能把差异完全归因于规划。
- dated_reference_schema_v1 进一步让模型输出证据 ID 到 subject/predicate 的 map，程序展开原文/日期/来源；承诺仍需实际作者肯定接受。只改变抽取协议，保留独立维护和全部费用。禁止未知引用或重复 JSON 键静默覆盖；总条数超额仍拒绝整批。引用协议不保证主语/属性正确，也不保证证据选全。


## D019：新增原始消息归档检索作为独立成本对照

- 日期：2026-10-16；状态：ArchiveStore/ArchivePolicy 已实现并通过针对性测试，真实模型对照进行中。
- 归档策略只为当前角色可见的原始消息生成向量，不执行摘要、importance、反思或事实抽取。原始会话及逐消息向量原子提交，完整作用域为 experimentId/worldId/agentId；重复写入不重复调用，原文/作者/时间在恢复时重新核验。
- 检索先按作用域和查询 as-of 的观察时间过滤，再以本地精确余弦排序，默认 Top-K=3、512-token 记忆预算，整条跳过超预算消息并留原因。不从评估答案选句，不为当前开发问题指定来源。
- 该策略不维护语义事实生命周期，也没有关键承诺 pinning、反思或混合策略自动回查。后来的历史转述会被较早的观察时间视图排除，不能将它等同分层事实有效期。
- 本轮是完整记忆策略对照，不能将全部差异单独归因于取消摘要。共同保留模型、数据、输入/输出上限、实际动作执行器与身份/UTC 修复，生成/向量/快照和质量分别报告。
